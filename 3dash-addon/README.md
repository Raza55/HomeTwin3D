# HomeTwin3D Add-on

Interaktiver 3D-Grundriss für Home Assistant mit Blender-Zuordnung, Licht-/Rollo-Steuerung, begehbarer Wohnung und Medienanzeigen.

Dieses Add-on gehört zum eigenständigen Projekt [HomeTwin3D](https://github.com/Raza55/HomeTwin3D), entstanden aus [3Dash](https://github.com/Kdcius/3Dash_webapp). Herkunft und Lizenz: [ORIGIN.md](../ORIGIN.md), [LICENSE](../LICENSE).

Nach dem Start: `http://<deine-ha-ip>:8099`. Ein parallel betriebenes 3Dash-Add-on benötigt einen anderen Host-Port. Die vollständige Einrichtung beschreibt [DOCS.md](DOCS.md).
